# بوت خدمة عملاء واتساب محلي ومجاني — n8n + Evolution API + Ollama

هذا مشروع بداية لبوت **نصي** يجيب عن رسائل العملاء بالعربية، مع نموذج ذكاء اصطناعي يعمل على جهازك باستخدام Ollama. لا يستخدم OpenAI أو Gemini أو أي API مدفوع. ملف سير العمل الجاهز للاستيراد هو:

[`../63_Free_WhatsApp_Customer_Service.json`](../63_Free_WhatsApp_Customer_Service.json)

## مهم قبل البدء: معنى «مجاني تمامًا»

- **لا توجد رسوم اشتراك أو رسوم API للذكاء الاصطناعي** في هذا الإعداد؛ Ollama والنموذج يعملان محليًا.
- لا تحتاج إلى VPS إذا شغّلت كل شيء على حاسوبك، لكن يجب أن يبقى الحاسوب والإنترنت والكهرباء متاحين كي يرد البوت.
- ربط WhatsApp هنا يتم عبر **Evolution API** وجلسة جهاز مرتبط، وليس عبر WhatsApp Business Cloud API الرسمي. هذا المسار غير رسمي وقد يتوقف أو يعرّض الرقم لتقييد من WhatsApp. جرّبه أولًا برقم ثانوي، ولا تستخدمه للإرسال الجماعي أو الرسائل غير المطلوبة.
- إذا كان الحفاظ على رقم النشاط أهم من شرط الصفر، فاستخدم WhatsApp Cloud API الرسمي. وفق صفحة تسعير Meta، اعتبارًا من 1 أكتوبر 2026 توجد 1,000 رسالة خدمة مجانية شهريًا لكل رقم أعمال؛ وقد تُفرض رسوم بعد الحد، كما تبقى تكاليف الاستضافة والاتصال منفصلة. [تفاصيل Meta الرسمية](https://developers.facebook.com/docs/whatsapp/pricing/).

إذًا: هذا الإعداد مجاني من ناحية البرمجيات والـ API، لكنه لا يجعل الكهرباء/الإنترنت مجانية ولا يضمن استخدام WhatsApp غير الرسمي بلا مخاطر.

## ما الذي يفعله سير العمل؟

1. يستقبل أحداث الرسائل من Evolution API عبر Webhook داخلي بين حاويات Docker.
2. يتجاهل رسائل البوت نفسه والمجموعات والبث.
3. يرسل نص العميل إلى نموذج `qwen2.5:3b` محليًا، مع ذاكرة قصيرة حسب رقم العميل.
4. يرسل الرد إلى العميل عبر Evolution API.
5. إذا وصلت صورة أو صوت أو رسالة بلا نص، يطلب من العميل كتابة استفساره؛ لا يحلل الوسائط في هذا الإصدار.

لا ينفّذ حجوزات أو مدفوعات أو تتبّع طلبات تلقائيًا؛ عدّل معلومات النشاط في تعليمات الوكيل، واربط أنظمة النشاط إذا احتجت تلك الميزات.

## المتطلبات

- Docker Desktop (Windows/Mac) أو Docker Engine وDocker Compose (Linux).
- اتصال إنترنت أول مرة لتنزيل صور Docker ونموذج اللغة (قرابة بضعة غيغابايت إجمالًا). بعد تنزيل النموذج، يعمل التوليد محليًا.
- يُفضّل 8 GB RAM أو أكثر. على الأجهزة الأضعف يمكنك استخدام `qwen2.5:1.5b` بدلًا من `qwen2.5:3b`، مع جودة أقل؛ عندها اسحب النموذج وعدّل اسم النموذج في عقدة Ollama.
- رقم واتساب لتجربة Evolution API. يُفضّل رقم اختبار منفصل بسبب مخاطر المسار غير الرسمي.

## التثبيت والتشغيل

افتح الطرفية داخل هذا المجلد:

```bash
cd workflows/63_Free_WhatsApp_Customer_Service
```

### 1. أنشئ ملف الأسرار المحلي

انسخ النموذج:

```bash
# Linux / macOS
cp .env.example .env

# Windows PowerShell
Copy-Item .env.example .env
```

أنشئ 3 قيم سرية عشوائية (نفّذ الأمر 3 مرات)، ثم ضع القيم في `.env` بدل النصوص التجريبية:

```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

ضع قيمة في كل من `EVOLUTION_API_KEY` و`POSTGRES_PASSWORD` و`N8N_ENCRYPTION_KEY`. لا تشارك `.env` ولا ترفع الملف إلى Git.

### 2. شغّل الخدمات

```bash
docker compose up -d
```

ثم نزّل النموذج المحلي:

```bash
docker compose exec ollama ollama pull qwen2.5:3b
```

تحقق من حالة الحاويات:

```bash
docker compose ps
```

واجهات الوصول محلية على هذا الجهاز فقط:

- n8n: <http://localhost:5678>
- Evolution API Manager: <http://localhost:8080/manager>
- قاعدة البيانات وRedis وOllama غير مكشوفة على منافذ جهازك.

### 3. جهّز n8n وسير العمل

1. افتح n8n وأنشئ حساب المالك عند أول تشغيل.
2. استورد ملف `63_Free_WhatsApp_Customer_Service.json` من **Workflows → Import from File**.
3. في عقدة **Ollama Qwen2.5 3B**، أنشئ/اختر بيانات اعتماد من نوع **Ollama** واجعل **Base URL**:
   `http://ollama:11434`
4. في عقدة **Send WhatsApp Reply**، أنشئ/اختر بيانات اعتماد **Header Auth**:
   - **Name:** `apikey`
   - **Value:** القيمة التي وضعتها في `EVOLUTION_API_KEY` داخل `.env`
5. افتح عقدة **AI Customer Support** واستبدل معلومات النشاط الوهمية (الاسم، المنتجات، الأسعار، التوصيل، ساعات العمل، وطريقة التصعيد لموظف) بمعلومات صحيحة.
6. احفظ سير العمل ثم فعّله. يجب أن يكون مفعّلًا كي يعمل رابط الإنتاج `/webhook/`.

> رابط الـ Webhook مضبوط مسبقًا داخل Compose على `http://n8n:5678/webhook/wa-customer-support-free`. هذا اسم خدمة داخل شبكة Docker؛ لا تستبدله بـ `localhost` في إعداد Evolution API.

### 4. اربط رقم واتساب

1. افتح <http://localhost:8080/manager> وأدخل قيمة `EVOLUTION_API_KEY` عند طلب مفتاح API.
2. أنشئ Instance جديدة، وافتح رمز QR، ثم من الهاتف اختر **الأجهزة المرتبطة → ربط جهاز** وامسح الرمز.
3. Compose يفعّل Webhook العام لأحداث الرسائل الواردة ويرسله إلى n8n. لا تحتاج إلى تفعيل تكامل N8N الخاص داخل Evolution Manager لهذا السير.
4. اختبر بإرسال رسالة نصية من رقم واتساب آخر إلى الرقم المرتبط. لن يجيب البوت على رسائل الرقم نفسه أو المجموعات.

## تخصيص معلومات النشاط

في عقدة **AI Customer Support** غيّر كتلة «معلومات النشاط» إلى شيء مثل:

```text
- اسم النشاط: متجر النيل
- المنتجات أو الخدمات: ملابس وأحذية
- الأسعار وسياسة التوصيل/الاسترجاع: التوصيل داخل أم درمان خلال يوم؛ الاستبدال خلال 3 أيام مع الفاتورة
- ساعات العمل والموقع: يوميًا من 9 صباحًا إلى 8 مساءً، أم درمان — [العنوان]
- طريقة التواصل مع موظف بشري: اكتب رقم أو طريقة التواصل المناسبة
```

لا تضع بيانات دفع أو كلمات مرور أو أسرار في تعليمات الوكيل. لا تترك أسعارًا أو سياسات غير مؤكدة كي لا يخمّنها النموذج.

## حدود النسخة الحالية

- رسائل نصية وتعليقات الصور/الفيديو/المستندات فقط. الصور والصوت غير محلّلة؛ يطلب البوت كتابة السؤال.
- الذاكرة تستخدم عقدة **Simple Memory** بآخر 6 تفاعلات تقريبًا، وهي ذاكرة مؤقتة وقد تُمسح عند إعادة تشغيل n8n.
- لا توجد لوحة تحكم للموظفين أو إدارة طلبات أو حفظ دائم للمحادثات.
- قد تكون إجابات النموذج المحلي أبطأ من الخدمات السحابية، وتعتمد على ذاكرة/قدرة جهازك.
- الرسائل ما زالت تمر عبر WhatsApp وEvolution API، كما يحفظ n8n بيانات التنفيذ محليًا. لا تستخدم بيانات حساسة، وراجع إعدادات الاحتفاظ بسجلات التنفيذ في n8n.

## استكشاف الأخطاء وإيقاف الخدمات

عرض السجلات:

```bash
docker compose logs -f evolution
# أو

docker compose logs -f n8n ollama
```

- لا يظهر تنفيذ في n8n: تأكد أن سير العمل **مفعّل**، وأن الهاتف متصل، وأن عنوان Webhook هو `http://n8n:5678/webhook/wa-customer-support-free`.
- يصل التنفيذ ولا يصل رد: راجع بيانات اعتماد Header Auth، ووجود النموذج عبر `docker compose exec ollama ollama list`.
- تعذر تنزيل النموذج: تأكد من الاتصال والمساحة الحرة ثم أعد أمر `ollama pull`.
- لإيقاف الحاويات مع الإبقاء على بياناتك: `docker compose down`.
- **تحذير:** `docker compose down -v` يحذف قواعد البيانات والنموذج والبيانات المحفوظة.
